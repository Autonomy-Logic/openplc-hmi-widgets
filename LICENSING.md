# Licensing

The OpenPLC HMI widget libraries are dual-licensed. You can use them under the **GNU General Public License v3** or under a **commercial licence** from Autonomy Logic Inc.

This covers every library of this repository and every archive a release publishes: the widget libraries (kind `hmi`) and the PLC-side HMI libraries (kind `plc`). Each archive states it in the release manifest as `GPL-3.0-only OR LicenseRef-Autonomy-Commercial`.

## GPLv3

The GPLv3 terms are in [LICENSE](LICENSE). Under the GPLv3 you may use, study, modify and share the libraries freely. If you distribute them, or a product that contains them, you must make the complete corresponding source code available under the GPLv3 to the people who receive it, including the HMI screens, PLC programs and other code that run combined with them.

## Commercial licence

The commercial licence for the HMI widget libraries comes with the OpenPLC Runtime commercial licence; there is no separate licence to buy for the widgets. A device that has a commercial OpenPLC Runtime licence may use the HMI widget libraries under the commercial licence, without the GPLv3 obligations. On a device without a commercial OpenPLC Runtime licence, the libraries are used under the GPLv3.

OpenPLC Runtime licences are bought from the OpenPLC Editor (desktop or web) when you upload a program to the device, and a licence is bound to the hardware it was bought for. See the [OpenPLC Runtime licensing](https://github.com/Autonomy-Logic/openplc-runtime/blob/development/LICENSING.md) for the details.

The libraries never restrict anything: they work the same way with or without a commercial licence.
